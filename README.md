# Yatharth’s personal site

Static GitHub Pages site. Open `index.html` for the portfolio. All content pages live in `pages/`, styles in `assets/css/`, scripts and catalogue data in `assets/js/`, and catalogue artwork in `assets/images/`. No build or installation is required.

## Catalogue

Public page: `pages/catalogue.html`. Local owner editor: `pages/catalogue-editor.html` (enabled only on localhost). The editor saves browser drafts; public visitors read `assets/js/catalogue-data.js` only. Export your draft and use the JSON array as `window.SAMPLE_ENTRIES` in that data file to publish your collection. Browser editing is not a remote authenticated publishing system.

The public catalogue currently contains explicitly labeled sample titles and opinions. Existing browser drafts are retained.

## Blog

`pages/blog.html` links to the existing Medium blog. The former Writing and Beyond URLs redirect here.
